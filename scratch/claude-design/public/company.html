01 / THESIS

Six beliefs behind the product.

Agents write the code, so write Rust

Rust has Charon and Aeneas, which turn safe Rust into pure functions a proof assistant can reason about.

Monorepos are the default

Agents build across a whole Cargo workspace. Its dependency graph tells rustproof which proofs a change invalidated.

Tests enforce behavior, not functions

The unit of verification is a behavior the system must keep. For pure functions, that behavior is a theorem.

Prove whenever possible

Code that can’t be extracted as written gets patched into the provable subset at build time.

I/O is a boundary, not a blocker

Prove the code before and after it. A theorem that takes the I/O result as an argument holds for every possible response.

The CI/CD system becomes your build engineer

It repairs what it is allowed to repair, patches what it is allowed to patch, and escalates what it isn’t.

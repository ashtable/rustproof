01 / ITS JOBS

What it does, and what it only proposes.

  • Explain why a proof fails, in plain language, with the counterexample.
  • Propose spec changes (never apply them) and proof repairs (apply them).
  • Explain a patch: which brick, why, and what the differential tests covered.
  • Recommend what to prove next, ranked by how provable and how important a function is.
  • Debug a failing run: extraction errors, unsupported Rust, cache misses.

Why is percent_bounded red?

rustproof agent · run_01HX4K

The claim is r ≤ 100 whenever done ≤ total. The counterexample finder found percent(42_949_673, 42_949_673): done * 100 overflows u32 before the division, so the function fails inside its own precondition.

Three standard resolutions. Widening the intermediate to u64 keeps the theorem exactly as approved, so it needs no new review.

02 / SAME RULES AS EVERY SURFACE

It has the build engineer’s authority, and no more.

It can write and repair proofs, apply built-in bricks, and change caches and config. It cannot change a theorem, apply a custom brick, or move the proof boundary. Those are proposals, approved by a person.
